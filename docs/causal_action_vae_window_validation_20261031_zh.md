# RTC 历史滑窗与视频 VAE：真实 NPU 验证

- 日期：2026-10-31，北京时间。
- 代码基线：`rtc` 分支 `7fca55c`。
- 模型：0930 `iter_000020000`，真实 Wan2.2 VAE，CFG=1、10步、①＋②。
- 数据：AgiBot task376 的 episode 27、28、30，既有固定评测清单的前三条。

## 1. 结论

本轮验证支持以下判断：

1. **当前历史窗口满足 VAE 的时间长度和因果规则。** 在短历史和满32块历史的固定形状实验中，只改变未来图像，已有条件 latent 均逐 bit 不变。
2. **移动窗口并重新初始化 VAE，会产生真实、可重复的历史特征差异。** 差异不只来自首帧，也不只是 BF16 舍入；短窗口内后续历史 latent 的相对差异明显。
3. **这些表示差异能够传到动作预测。** 普通推理没有 RTC VJP 重复波动，同输入重复及无操作注入均精确一致；替换 VAE 表示后，动作确实发生变化。
4. **不能把上述差异称为确定的精度损失，也不能据此断言 `s=8` 比 `s=16` 更差。** 较早上下文裁剪是敏感性对照，不是金标准；不同 `s` 案例发生在不同请求时刻。对参考动作的误差有改善也有变差。

本轮没有修改 VAE、模型、采样算法或默认执行配置，也没有启用跨轮模型缓存。真实仿真/机器人闭环和任务成功率不在本轮范围内。

## 2. 实验范围与控制变量

| 项目     | 设置                                                                             |
| -------- | -------------------------------------------------------------------------------- |
| VAE 专项 | 24个窗口案例，主实验64次 encode，补充6次 encode，共70次                          |
| 动作专项 | 16个案例、110次记录内模型调用，另做1次恢复实验 hook 后的普通推理检查             |
| 设备     | 物理 NPU1 做 VAE 专项，NPU2 做动作专项，结束后均释放                             |
| 输入图像 | 生产预处理后的640×640 RGB，真实观测，视频 stride=4                               |
| VAE 配置 | 时间压缩4、24张 RGB 的内部 chunk、checkpoint 的 exact-duration 列表、BF16、eager |
| 普通推理 | CFG=1、10步、完整请求内缓存，固定 seed42                                         |
| RTC 子集 | beta=5，`d=4`，`P=16`或24，每种表示重复2次                                       |
| 历史长度 | 短窗口1/2/3块；VAE 专项满32块有3条轨迹，动作专项满32块只有 episode27             |

RTC 的 `d=4` 是本轮引导参数，不代表真实推理只耗时4个控制周期。本轮没有执行 client/server 调度或测试 RTC deadline。

相同案例中保持当前 state、anchor、文本、mask、动作 horizon、噪声种子、网络位置和 RTC 旧预测 prefix 一致，只替换已观测的视频 latent。RTC prefix 来自前一次模型预测，不来自 GT；未来 GT 图像没有输入策略。

## 3. 如何正确比较滑窗与较早起点编码

当前请求时刻为 `t`，历史窗口为：

```text
h = min(t // 32, 32)
left = t - 32*h
真实RGB时刻 = left, left+4, ..., t
本地VAE输出 = 1 + 2*h 个latent
```

`s=8` 的新窗口可以相对 episode 起点偏移8个动作点，相当于2张采样 RGB；这不是 VAE 4倍压缩的完整步长。因此不能把起点0和起点8的不同 latent 时间网格直接相减。

本轮参考编码使用：

```text
reference_origin = t % 16
reference_RGB = reference_origin, reference_origin+4, ..., t
crop_offset = (left-reference_origin) // 16
reference_crop = reference_latent[crop_offset : crop_offset+1+2*h]
```

这样，本地和参考 latent 的名义绝对时刻一致。对于 `s=8` 相位，reference 可能从8开始，不能把它叫作从 episode 第0帧持续编码。

另有两个重要限定：

- 本地第0个 latent 是独立首帧 prime；reference 在相同时刻的 latent 可能聚合更早上下文。该项单独评分，不能混作全部历史误差。
- 额外在 episode27 的 `t=48/56` 保留本地首 latent，只替换后续历史 latent，以判断影响是否仅来自首帧替换。

这是固定网络布局下的 VAE 表示敏感性实验，不等于复现整个训练片段的 Transformer 注意力状态，也没有证明参考编码更符合训练分布。

## 4. 编码原则与重复性检查

| 检查                                         | 结果                                                     |
| -------------------------------------------- | -------------------------------------------------------- |
| 真实观测 `1+8h` 张 RGB → `1+2h` 个 latent    | 全部合法                                                 |
| 总长17张：固定前9张，只把后8张图像反色       | 3/3轨迹的前3个 latent 逐 bit 不变，未来 latent 实际改变  |
| 总长265张：固定前257张，只把后8张图像反色    | 3/3轨迹的前65个 latent 逐 bit 不变，未来 latent 实际改变 |
| 相同窗口重复编码                             | 6/6逐 bit 相同                                           |
| 窗口起点与参考起点相同的负对照               | 6/6逐 bit 相同                                           |
| 普通模型：生产编码 vs 本地 latent 无操作注入 | 16/16案例逐 bit 相同                                     |
| 普通模型：相同 reference 重复推理            | 16/16案例逐 bit 相同                                     |
| 恢复实验 hook 后再运行普通推理               | 与此前对应结果逐 bit 相同                                |

固定总长度的未来干预是主要因果性判据。单独比较短前缀与更长视频时，总形状和内部尾 chunk 可能不同：本轮9张 vs17张的公共前缀出现过约0.15%的特征相对差异，257张 vs265张也出现过小差异。不能仅凭这类不同形状对照判断“看到了未来”。

本轮满历史 episode27/t1040 的最新两个 latent 在完整画布口径下约0.160%差异，可由257张 vs265张的尾 chunk 数值路径完整复现；该例中，对齐参考末尾与对应长形状控制末尾逐 bit 一致。

## 5. 历史 latent 的实际差异

以下相对 RMSE 为 `norm(local-reference)/norm(reference)`。先对每条轨迹计算，再平均3条轨迹的比值。它是特征差异，**不是动作误差增加百分比**。

下表使用动作模型实际保留的40×35 latent区域，排除右侧 padding，由独立脚本复算。原始 VAE 专项报告还保留了完整40×40画布的统计，两种口径数值略有不同。

| 请求时刻 | 历史块数 | 窗口起点/参考起点 | 排除首 prime 的历史相对 RMSE | 最近两个 latent 相对 RMSE |
| -------- | -------- | ----------------- | ---------------------------- | ------------------------- |
| 40       | 1        | 8/8               | 0.00%                        | 0.00%                     |
| 48       | 1        | 16/0              | 17.66%                       | 17.66%                    |
| 56       | 1        | 24/8              | 17.08%                       | 17.08%                    |
| 80       | 2        | 16/0              | 14.57%                       | 10.98%                    |
| 88       | 2        | 24/8              | 14.22%                       | 10.89%                    |
| 96       | 3        | 0/0               | 0.00%                        | 0.00%                     |
| 1040     | 32       | 16/0              | 3.96%                        | 0.052%                    |
| 1048     | 32       | 24/8              | 3.90%                        | 0.00%                     |

首 prime 的相对差异约54%～56%，已从上述“后续历史”列排除。长窗口的差异主要集中在左侧；后续大量相同 latent 会稀释整体比例，不能把“约4%”解释为边界差异消失。

满历史最新两个 latent 中，除了上述能被形状控制复现的 episode27/t1040，其余均逐 bit 相同。

## 6. 差异是否传到了动作

### 6.1 普通推理：无 RTC 重复波动的配对对照

下表是“当前窗口编码”与“较早上下文裁剪”的**输出之间差异**，不是对 GT 的误差。每个短窗口行平均3条轨迹，满历史两行各只有1条轨迹。

| 请求时刻与相位              | 轨迹数 | 关节 MAE    | EEF位置距离 | EEF姿态角 | 夹爪差，原单位 |
| --------------------------- | ------ | ----------- | ----------- | --------- | -------------- |
| t48，s16相位，1块历史       | 3      | 0.00203 rad | 0.73 mm     | 0.65°     | 0.144          |
| t56，s8新增相位，1块历史    | 3      | 0.00719 rad | 3.02 mm     | 0.86°     | 0.194          |
| t80，s16相位，2块历史       | 3      | 0.00327 rad | 0.90 mm     | 0.74°     | 0.138          |
| t88，s8新增相位，2块历史    | 3      | 0.00180 rad | 0.79 mm     | 0.65°     | 0.141          |
| t1040，s16相位，32块历史    | 1      | 0.00074 rad | 0.36 mm     | 0.48°     | 0.099          |
| t1048，s8新增相位，32块历史 | 1      | 0.00142 rad | 0.70 mm     | 0.47°     | 0.114          |

`s16`和`s8`行的时刻、画面和目标不同，不能从这张表得出“小s必然更差”。不过，同一案例内普通推理重复和无操作注入精确一致，支持“VAE上下文变化能够改变动作”的因果解释。

平均值也不能掩盖少量较大差异。全部短历史普通推理对照中，s8标记案例观察到的最大关节分量差约4.98°、最大末端位置距离约15.46 mm；s16标记案例分别约2.63°、2.55 mm。这些仍是跨表示输出差，不是 GT 误差增长，也不是重规划节奏的公平优劣比较。

保留本地首 prime、只替换后续历史的对照，也没有消除差异：episode27/t48 的关节差约0.00283 rad、姿态差约0.71°；t56约0.00102 rad、0.41°。因此影响并非全部来自把历史聚合 latent 放到首帧位置。

### 6.2 RTC：把表示变化与自身重复波动分开

RTC 每种表示重复2次，跨表示差异取四个重复配对的均值；只评分尚未承诺执行的后28步。所有已提交前4步保持精确一致。

| 案例组         | 跨表示关节差 | 当前表示自身重复关节差 | 跨表示位置差 | 跨表示姿态差 | 当前表示自身重复姿态差 |
| -------------- | ------------ | ---------------------- | ------------ | ------------ | ---------------------- |
| t48，3条轨迹   | 0.00210 rad  | 0.00050 rad            | 0.73 mm      | 0.64°        | 0.32°                  |
| t56，3条轨迹   | 0.00766 rad  | 0.00049 rad            | 3.25 mm      | 0.87°        | 0.34°                  |
| t1040，1条轨迹 | 0.00074 rad  | 0.00041 rad            | 0.39 mm      | 0.42°        | 0.37°                  |
| t1048，1条轨迹 | 0.00156 rad  | 0.00042 rad            | 0.78 mm      | 0.49°        | 0.32°                  |

短历史的跨表示差异大于自身重复量级；长历史部分指标已接近重复波动。不能把跨表示 RTC 差值全部归因于 VAE，也不能把它全部解释成 VJP 的数值波动。

### 6.3 对参考动作的误差有改善也有变差

以普通推理、3条轨迹均值为例，箭头表示“当前窗口 → 较早上下文裁剪”，越小越好：

| 请求时刻 | 关节参考 MAE        | EEF位置参考误差 | EEF姿态参考误差 |
| -------- | ------------------- | --------------- | --------------- |
| t48      | 0.04628→0.04635 rad | 16.07→16.04 mm  | 3.65→3.45°      |
| t56      | 0.04498→0.04531 rad | 14.89→14.44 mm  | 2.75→2.77°      |

这不支持“连续编码在每个指标都更好”，也不能把输出差当作精度下降量。GT 是已对齐的下一状态参考 `state[t+1]`；原0930训练统计量未完全确认，样本不是独立 held-out，任务数和轨迹数也不足以给出泛化或成功率结论。

## 7. 独立核验与审计说明

独立 CPU 脚本直接从保存张量重算 latent 误差、关节/位置误差与四元数相对旋转角，不导入实验中的指标函数。还检查了参考 crop、图像/latent时间索引、source hash、已提交前缀，以及动作无操作/重复对照。

最终独立核验通过62,891项检查，其中54,999项为数值复算，零失败。24个VAE案例和16个动作案例均覆盖；两个实验的15个重合案例中，local及reference crop跨NPU逐 bit 相同。

一个日志命名问题已单独核对：动作实验原字段 `noise_sha256` 实际记录的是**条件和噪声混合后的初始状态**，改变观测 latent 后其 SHA 理应变化。独立核验按生产代码重建固定 seed42 的纯随机噪声，结合保存的条件、实际40×35 latent裁剪和BF16动作噪声，对102个非bootstrap当前请求均精确恢复了记录的初始状态 SHA。早期把该字段跨条件相等作为要求的检查已被此独立重构取代，最终验证状态为通过。

VAE专项与动作专项在不同 NPU 上生成的匹配 local/reference latent 也进行了交叉核对，以排除预处理或 VAE 配置不一致。

## 8. 对当前实现的判断和后续验证

当前实现可称为“每轮把观测窗口当成独立合法视频重新编码”。本轮没有发现因果性或帧数规则错误；同时确认了跨窗口上下文不等价，以及它对动作的敏感性。

在决定是否改成固定起点流式编码、增加 VAE warmup 上下文或引入跨轮缓存之前，还需要：

1. 明确想保持的是“独立训练片段的首帧语义”还是“持续流的编码语义”，避免把不同合法条件混称严格等价。
2. 对相同任务和时间点，评估相应策略对动作参考误差、连续性、耗时和显存的影响。
3. 在真实仿真闭环中测试多种执行倍率和重规划节奏。录制观测不会响应预测动作，本轮没有检验慢执行后的动力学分布。
4. 如果复用跨轮 latent/KV，单独保证时间相位、首帧、VAE状态和模型位置一致；当前②仅限请求内复用，不能直接拼接旧相位缓存。
